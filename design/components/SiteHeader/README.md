The bar at the top of every page: the monogram and name on the left, navigation on the right, closed by a strong rule.

- Provide the five links in this order: Work, Publications, Teaching, About, CV. Type them in sentence case; CSS lowercases them.
- Mark the current page with `aria-current="page"`, which underlines it.
- Add Writing between Work and Publications only once the first piece is published.
- The bar wraps on a narrow screen: the name takes the first row and the links the second. Do not replace the links with a menu button.
- The header markup is repeated in every page file, so the navigation works without JavaScript.
